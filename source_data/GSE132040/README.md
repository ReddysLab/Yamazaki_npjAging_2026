Public source-data reference for Schaum et al. / Tabula Muris Senis aging analyses (GSE132040).

Download the analyzed `.h5ad` object from the public repository and set `NPJAGING_SCHAUM_H5AD` to its local path, or place it at `source_data/GSE132040/tabula_muris_senis.h5ad`. `mouse_gene_map.csv` contains the mouse-symbol mapping used for the cross-species overlap.
